# 万年历（WanNianLi）

一个 Android 万年历应用：公历 + 农历 + 干支 + 节气 + 节日，并提供可放置在桌面的微件（Widget）。

## 显示格式

```
西元2026年10月18日第42周星期日
黄帝纪元四七二三年九月九日丙午年（马）戊戌月乙丑日　重阳节
```

（第一行行尾的阳历节日/角色生日以半角空格分隔；第二行行尾的农历节日/节气以全角空格「　」分隔）

- **第一行**：西元（公历）日期、ISO-8601 周数、星期；**阳历节日与《原神》角色生日附于行尾**（二者皆按公历日期）
- **第二行**：黄帝纪元年份（= 农历年 + 2697，**以春节为界，与干支年同岁**，逐位读作「四七二三」）、农历月日、干支年（生肖）、干支月、干支日；**农历节日与二十四节气附于行尾**（节气属农历阴阳合历体系）

## 功能

- **今日详情卡**：完整两行标准格式 + 干支/生肖/农历/节气/节日/时辰/距今天数
- **显示设置**（右上角齿轮）：主题可选「跟随系统 / 暗色（水墨）/ 亮色（宣纸，适合墨水屏）」；农历日期可在「九月九日（书面体，古诗文正体，如《九月九日忆山东兄弟》）」与「九月初九（传统体，口语习惯）」间切换；「廿」与「二十」、「卅」与「三十」写法独立可选；微件背景可选「暗色卡片 / 半透明磨砂 / 透明」。设置对主界面与桌面微件同时生效并持久化
- **月历网格**：左右滑动翻月；标题行支持 ◀◀ 上一年 / ◀ 上月 / ▶ 下月 / ▶▶ 下一年；标注农历日、节日（朱砂色）、节气（青色）、角色生日（紫色）；今日金色高亮、选中朱砂圆点
- **桌面微件**：提供 4×2、4×1、2×2 三种尺寸（微件列表中的「万年历 4×2 / 4×1 / 2×2」），均可缩放；点击打开应用；跨零自动刷新（AlarmManager + DATE_CHANGED + 开机三重保障）
- **《原神》角色生日**：收录 120 位角色（数据来自原神 WIKI_BWIKI 各角色页，2026-10 抓取），在月历网格（紫色标记）、今日详情卡、月度汇总及微件中展示；同一天多位角色会合并显示（如「久岐忍、可莉生日」）；可在设置中关闭
- 支持 **1900 - 2100** 年，含闰月（如 2025 闰六月）、除夕、24 节气

## 历法实现说明

| 项目 | 算法 |
| --- | --- |
| 农历 | 经典农历信息表（1900-2100，含闰月与大/小月） |
| 节气 | Meeus 低精度太阳视黄经公式 + 牛顿迭代求交节时刻，转北京时间定日期 |
| 年柱 | `(农历年 - 4) mod 60`，以春节为界 |
| 月柱 | 以「节」定月（遇节换月），年干按「五虎遁」推月干 |
| 日柱 | 由儒略日推算：`(JDN + 49) mod 60 == 0` 为甲子日 |
| 周数 | ISO-8601（周一为一周首日） |
| 黄帝纪元 | 农历年份 + 2697（春节为界，与干支年同岁） |

核心算法（`app/src/main/java/com/yx/wannianli/calendar/`）为纯 Kotlin 无 Android 依赖，
已经过 46 项自动化校验（春节/闰月/节气/日柱/5000 次随机正逆向转换等）。

## 构建

需要 Android Studio（Ladybug 或更新版本）与 Android SDK 35。

```bash
# 命令行构建
./gradlew assembleDebug        # 产出 app/build/outputs/apk/debug/app-debug.apk
```

或直接用 Android Studio 打开本目录，同步 Gradle 后运行。

安装后在桌面长按 → 小部件 → 选择「万年历 4×2 / 4×1 / 2×2」（均可缩放）。

## 目录结构

```
app/src/main/java/com/yx/wannianli/
├── MainActivity.kt                 # 入口
├── calendar/                       # 历法核心（纯 Kotlin）
│   ├── LunarCalendar.kt            #   农历数据表与换算
│   ├── SolarTerms.kt               #   二十四节气
│   ├── Ganzhi.kt                   #   干支/生肖/时辰
│   ├── Festivals.kt                #   节日
│   ├── GenshinBirthdays.kt         #   原神角色生日数据（120 位）
│   ├── ChineseNumerals.kt          #   中文数字
│   ├── JulianDays.kt               #   儒略日
│   └── WanNianLi.kt                #   门面：CalendarDay 与月网格
├── ui/                             # Compose 界面
├── widget/                         # 桌面微件（4×2 / 4×1 / 2×2 三种尺寸）
│   ├── CalendarWidgetProvider.kt   #   基类 + 两个尺寸子类 + 统一刷新
│   └── WidgetAlarm.kt              #   跨零定时
```
